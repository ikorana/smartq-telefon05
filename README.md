# telefon05

Smart Home Pelephone — SmartQ akıllı ev otomasyonu donanımı ("ana kutu") için geliştirilen kapsamlı companion mobil uygulaması.

## About

telefon05 is the full-featured companion app for the SmartQ "ana kutu" home automation controller — supporting multi-user device/room/scene management, UDP and MQTT communication, speech-to-text voice commands, push notifications, and more.
